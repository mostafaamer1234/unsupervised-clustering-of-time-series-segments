MethodClustersARINMIPurity

Adjusted Rand Index, where 0 is chance. Every shape-based method is near chance. A phase-invariant spectrum lifts k-means about seven times above the best shape-based score.

Where each signal is most active.

Kadane's algorithm finds the stretch with the most change. The first version always returned the whole signal, because change is never negative. Centering it on the signal's own average fixed that, and a test now guards it.

Pick a pivot, split the set at the median distance to it, recurse until clusters are small or tight. Seeded, so runs repeat.
